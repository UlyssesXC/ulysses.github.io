# Images Folder

Place your image files in this folder.

## Required Avatar Images

- `avatar.jpg` - Your default avatar (recommended size: 160x160 pixels or larger square image)
- `avatar-hover.jpg` - Avatar shown on hover (recommended size: 160x160 pixels or larger square image)

## Project Demo Images/GIFs

Based on your content, you may want to add:

- `robot-sim.gif` - Inspection robot simulation demo
- `robot-working.gif` or `robot-working-1.jpg`, `robot-working-2.jpg` - Robot working on production line
- Any other project demos or technical diagrams

## Other Images

You can place any images or GIFs you want to use on your website here.

To reference them in Markdown, use relative paths:

```markdown
![Description](images/your-image.jpg)
![GIF animation](images/animation.gif)
```

## Image Format Recommendations

- Avatars: JPG or PNG
- Content images: JPG (photos), PNG (images with transparency)
- Animations: GIF or WEBP

## Optimization Tips

For faster website loading:
- Compress large images
- Keep GIF files small (recommended < 2MB)
- Use appropriate resolution (web display typically doesn't need ultra-high resolution)

## Online Compression Tools

- **Images:** [TinyPNG](https://tinypng.com/)
- **GIFs:** [ezgif.com](https://ezgif.com/optimize)

## File Naming

- Use English filenames
- Avoid spaces (use hyphens `-` instead)
- Use lowercase letters
- Be descriptive: `robot-inspection-demo.gif` instead of `demo1.gif`
